# 📋 Checklist para GitHub Pages

## ✅ Paso 1: Cuenta GitHub
- [ ] Ir a github.com
- [ ] Crear cuenta gratuita
- [ ] Verificar email

## ✅ Paso 2: Crear Repositorio
- [ ] Click en "New repository"
- [ ] Nombre: `market-shopping-app`
- [ ] Descripción: `App de compras del mercado con conversión de monedas`
- [ ] Tipo: Public (☑️)
- [ ] NO agregar README, .gitignore, license
- [ ] Click "Create repository"

## ✅ Paso 3: Subir Archivos
- [ ] Click "uploading an existing file"
- [ ] Arrastrar archivos:
  - index.html
  - styles.css
  - script.js
  - CÓMO_USAR_EN_TELÉFONO.md
- [ ] Commit changes: "Subir app Market Shopping"
- [ ] Click "Commit changes"

## ✅ Paso 4: Activar GitHub Pages
- [ ] Ir a "Settings" del repositorio
- [ ] Buscar "Pages" en menú izquierdo
- [ ] Source: "Deploy from a branch"
- [ ] Branch: "main"
- [ ] Folder: "/ (root)"
- [ ] Click "Save"

## ✅ Paso 5: Obtener URL
- [ ] Esperar 2-3 minutos
- [ ] Volver a "Settings" → "Pages"
- [ ] Copiar URL que aparece
- [ ] Probar en navegador
